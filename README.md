# Jejak Fluktuasi Penumpang Kereta Api Evaluasi Tingkat Permintaan Layanan Berbasis Python
## Tujuan Pembuatan
 Program ini dirancang untuk mengelola data penumpang kereta api dari _file_ CSV untuk memprediksi fluktasi penumpang di bulan mendatang dan mengevaluasi dan menidaklanjuti jumlah penumpang pada bulan-bulan sebelumnya. Program ini juga dirancang untuk regristrasi dan login untuk menjaga rahasia operasional aplikasi
